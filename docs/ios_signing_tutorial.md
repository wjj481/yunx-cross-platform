# iOS 端 IPA 签名与安装教程（爱思助手）

> 本教程指导你如何为 YunX 跨平台下载工具的 iOS 安装包（IPA）进行自签名，并通过爱思助手（i4Tools）安装到 iPhone / iPad 上。
>
> **适用系统**：Windows 7/8/10/11（32位/64位均可）、macOS 10.13+
> **适用设备**：iPhone / iPad（iOS 12.0 及以上，无需越狱）

---

## 一、前期准备

### 1.1 所需材料

| 材料 | 说明 | 获取方式 |
|------|------|----------|
| IPA 安装包 | YunX iOS 端安装包 | GitHub Release 页面下载 `YunX-iOS-vX.X.X.ipa` |
| 爱思助手 | iOS 设备管理工具 | 官网 https://www.i4.cn 下载（免费，无需会员） |
| Apple ID | 普通个人 Apple ID 即可 | https://appleid.apple.com 免费注册 |
| 数据线 | 原装或 MFi 认证数据线 | 用于连接设备与电脑 |
| iPhone / iPad | iOS 12.0 及以上 | 目标安装设备 |

### 1.2 安装爱思助手

1. 浏览器访问 https://www.i4.cn
2. 点击「下载爱思助手」，选择对应系统版本（Windows 版 / Mac 版）
3. 下载完成后双击安装，按提示完成安装
4. 安装过程中会自动安装 iTunes 驱动（如未安装过 iTunes），按提示确认即可

> **注意**：Windows 32位系统请下载「爱思助手 32位版」，64位系统两个版本均可使用。

## 二、获取 IPA 安装包

### 方式一：从 GitHub Release 直接下载（推荐）

1. 访问项目 Release 页面：https://github.com/wjj481/yunx-cross-platform/releases
2. 找到最新版本，下载 `YunX-iOS-vX.X.X.ipa` 文件
3. 记住文件保存位置（建议保存到桌面，方便后续查找）

### 方式二：自行通过 GitHub Actions 构建

如果 Release 中未提供预构建 IPA，可自行触发 GitHub Actions 构建：

1. Fork 本仓库到你的 GitHub 账号
2. 进入仓库的 **Actions** 标签页
3. 选择 **Build iOS IPA** 工作流
4. 点击 **Run workflow**，选择分支 `main`，点击绿色 **Run workflow** 按钮
5. 等待构建完成（约 15-30 分钟，macOS  runner 较慢）
6. 构建完成后，进入该次运行详情，在 **Artifacts** 区域下载 `YunX-iOS.ipa`

> **说明**：GitHub Actions 的 macOS 运行器免费额度为每月 2000 分钟（macOS 按 10 倍计费，即实际 200 分钟），个人账号完全够用。

## 三、使用爱思助手签名并安装

### 3.1 连接设备

1. 用数据线将 iPhone / iPad 连接到电脑
2. 解锁设备，屏幕上会弹出「是否信任此电脑」，点击**信任**并输入设备密码
3. 打开爱思助手，等待左侧设备列表中显示你的设备名称和信息
4. 确认爱思助手主界面显示「已连接」，设备信息（型号、iOS版本、序列号等）正常显示

> **常见问题**：如果爱思助手无法识别设备，请检查：
> - 数据线是否为原装或 MFi 认证（部分充电线无法传输数据）
> - 是否在设备上点击了「信任」
> - iTunes 驱动是否安装成功（爱思助手菜单 → 帮助 → 修复驱动）

### 3.2 进入「签名安装」功能

1. 在爱思助手顶部菜单栏，点击 **工具箱**
2. 在工具箱页面找到并点击 **IPA 签名**（部分版本叫「签名安装」或「应用签名」）
3. 进入 IPA 签名界面

### 3.3 添加 IPA 文件

1. 在 IPA 签名界面，点击 **添加 IPA 文件** 按钮
2. 在文件选择窗口中，找到并选中之前下载的 `YunX-iOS-vX.X.X.ipa`
3. 点击「打开」，文件会出现在签名列表中

### 3.4 配置签名证书

#### 使用个人 Apple ID 签名（免费，推荐）

1. 在签名列表中，点击该 IPA 右侧的 **签名** 按钮（或「选择证书」下拉框）
2. 在弹出的证书选择窗口中，点击 **添加 Apple ID**（或「使用 Apple ID 签名」）
3. 输入你的 **Apple ID 账号**（邮箱）和**密码**，点击「登录」
4. 如果开启了双重认证，手机上会收到验证码，在电脑上输入6位验证码
5. 登录成功后，爱思助手会自动生成个人开发证书
6. 在证书列表中选中刚添加的证书，点击「确定」

> **关于个人免费证书的限制**：
> - 签名的 App 有效期为 **7 天**，7 天后需要重新签名安装（数据不会丢失）
> - 同一个 Apple ID 最多同时签名 **3 个** App
> - 这是 Apple 对个人免费开发者账号的限制，无法绕过
> - 如需长期有效，可购买 Apple 开发者账号（$99/年），签名有效期 1 年

#### 使用企业证书签名（如有）

如果你有企业开发者账号（$299/年）的证书和描述文件：

1. 在证书选择窗口点击「导入证书」
2. 选择 `.p12` 证书文件，输入证书密码
3. 选择对应的描述文件（`.mobileprovision`）
4. 点击确定

> 企业证书签名的 App 有效期为 1 年，但需要在设备上「设置 → 通用 → VPN与设备管理」中信任企业开发者证书。

### 3.5 开始签名

1. 确认证书已选中，点击 **开始签名** 按钮
2. 等待签名完成（通常 10-30 秒）
3. 签名成功后，列表中状态显示「已签名」，并显示签名证书和过期时间

### 3.6 安装到设备

签名完成后，有两种安装方式：

#### 方式一：直接安装（推荐）

1. 在已签名的 IPA 右侧，点击 **安装到设备** 按钮
2. 爱思助手会自动将 App 安装到已连接的 iOS 设备上
3. 等待安装完成，设备桌面上会出现 YunX 图标

#### 方式二：导出已签名 IPA 后手动安装

1. 点击 **导出已签名 IPA**，选择保存位置
2. 然后在爱思助手主界面点击 **应用游戏** → **导入安装**
3. 选择刚导出的已签名 IPA 文件进行安装

### 3.7 信任开发者证书（必须步骤）

安装完成后，首次打开 App 会提示「未受信任的企业级开发者」或「无法打开」：

1. 在 iPhone / iPad 上打开 **设置**
2. 进入 **通用** → **VPN 与设备管理**（iOS 15 及以上）或 **通用** → **设备管理**（iOS 14 及以下）
3. 在「开发者 App」或「企业级 App」分类下，找到你的 Apple ID 对应的证书
4. 点击进入，点击 **信任 "你的AppleID"**
5. 在弹出的确认框中再次点击「信任」
6. 返回桌面，点击 YunX 图标即可正常打开

## 四、7天后重新签名（个人免费证书必看）

个人 Apple ID 签名的 App 7 天后会闪退无法打开，需要重新签名：

1. 打开爱思助手，连接设备
2. 进入 **工具箱** → **IPA 签名**
3. 点击 **添加 IPA 文件**，重新添加原始 IPA（或从设备中导出已安装的 IPA）
4. 使用同一个 Apple ID 再次签名
5. 点击「安装到设备」覆盖安装（**数据不会丢失**，下载记录和配置都会保留）
6. 安装完成后即可正常使用

> **小技巧**：可以在爱思助手「IPA 签名」界面开启「签名后自动安装」，下次重签更快捷。

## 五、常见问题排查

### Q1：签名时提示「此 Apple ID 已达到 App ID 数量上限」

**原因**：个人免费 Apple ID 最多创建 10 个 App ID（不同 Bundle ID）。
**解决**：
- 登录 https://developer.apple.com/account → 「证书、标识符和配置文件」→「Identifiers」
- 删除不再使用的 App ID
- 或使用另一个 Apple ID 签名

### Q2：安装后打开闪退

**可能原因及解决**：
1. **证书过期**（7天到了）→ 按第四节重新签名
2. **未信任证书** → 按 3.7 节在设置中信任
3. **设备不支持** → YunX iOS 端要求 iOS 12.0 及以上，请检查系统版本
4. **签名过程出错** → 删除设备上的 App，重新签名安装

### Q3：爱思助手提示「设备未越狱，部分功能不可用」

YunX 不需要越狱即可安装运行。爱思助手的部分高级功能（如文件系统全访问）需要越狱，但签名安装功能不需要。忽略该提示即可。

### Q4：Windows 32位系统能使用爱思助手吗？

可以。爱思助手提供 32 位版本，在官网下载页面选择「32位版」即可。Windows 7 32位也可正常使用。

### Q5：macOS 上如何操作？

爱思助手有 Mac 版，操作流程与 Windows 版完全一致。下载地址：https://www.i4.cn（选择 Mac 版下载）。

### Q6：可以不连电脑直接在手机上签名吗？

不可以。Apple 要求签名操作必须通过电脑端工具完成。这是系统限制，所有自签名方案（爱思助手、AltStore、Sideloadly 等）都需要电脑。

### Q7：AltStore / Sideloadly 可以用吗？

可以。除了爱思助手，你也可以使用以下工具进行自签名：
- **AltStore**（https://altstore.io）：免费，支持 Wi-Fi 刷新签名
- **Sideloadly**（https://sideloadly.io）：免费，界面简洁
- **TrollStore**（仅支持特定 iOS 版本，永久签名，无需电脑）

操作原理相同：导入 IPA → 登录 Apple ID → 签名 → 安装 → 信任证书。

## 六、卸载与数据清理

### 卸载 App

1. 长按桌面 YunX 图标 → 点击「移除 App」→「删除 App」
2. 或在爱思助手「应用游戏」中选中 YunX → 点击「卸载」

### 清理下载数据

App 卸载后，其沙盒内的所有数据（下载文件、配置、凭证）会被系统自动清除。如需在卸载前备份下载文件：
1. 爱思助手 → 「应用游戏」→ 找到 YunX → 点击「浏览」（文件共享）
2. 将 Documents 目录下的文件导出到电脑

## 七、安全与免责声明

1. **Apple ID 安全**：爱思助手使用你的 Apple ID 仅用于生成本地签名证书，不会上传你的密码到第三方服务器。但仍建议使用专门的小号 Apple ID 进行签名，不要使用主账号。
2. **数据安全**：YunX 的凭证（网盘 Cookie/JWT）使用 AES-GCM 加密存储在设备本地沙盒中，不会上传到任何服务器。
3. **网络安全**：仅从本项目官方 GitHub Release 下载 IPA，不要使用来路不明的 IPA 文件，防止被植入恶意代码。
4. **免责声明**：本工具仅供个人学习和技术交流使用，请勿用于商业用途。通过本工具下载的内容请在 24 小时内删除。使用自签名 App 违反 Apple 服务条款的风险由用户自行承担。
